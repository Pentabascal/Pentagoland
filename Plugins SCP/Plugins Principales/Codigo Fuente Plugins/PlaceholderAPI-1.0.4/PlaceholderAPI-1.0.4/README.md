# Información
PlaceholderAPI es un plugin para servidores Exiled que permite mostrar información dinámica en comandos, apodos, datos de jugadores y otros plugins. Para facilitar su uso, emplea un formato estándar.

Algunos plugins admiten marcadores de forma nativa, mientras que otros necesitan expansiones. Puedes descargar estas expansiones directamente en el juego desde PAPI Expansion Cloud.

(Este proyecto no es el original: es una adaptación de Minecraft a SCP:SL).

## Usar expansiones
Usar marcadores de plugins o expansiones es muy sencillo. Solo tienes que introducir el marcador con el formato adecuado (por ejemplo, %player_name%) en cualquier ajuste que lo admita. Consulta el manual o la wiki del plugin para saber dónde puedes usarlos.

Para más información, visita la [wiki](https://github.com/PlaceholderAPI-SL/PlaceholderAPI/wiki).

- Este directorio se utilizara únicamente para instalar y mantener guardados los Plugins que se utilicen para el verdadero Servidor. Aquí estarán los códigos fuentes, archivos de configuración, dll, todo que este relacionado con cualquier plugin habilitada o deshabilitada, que se use posteriormente o no. Estara distribuido de forma ordenada para estar organizados y una instalación fácil. Manten este lugar como tu workspace, aquí realiza todas las modificaciones que desees o crea cualquier plugin o cosa aquí. El directorio del servidor (Dedicated Server o EXILED) Se mantendrán lo mas limpio posible, trata de solo usar eso cuando este el proyecto finalizado, cuando haya que probar una plugin, cuando quieras meter algo para ver el resultado de los logs, solo cuando sea necesario. Aquí haz todas las operaciones.

Siempre que sea posible, intenta utilizar las plugins que se te son facilitadas, evita crear una plugin tuya propia ya que eso puede desestabilizar las cosas y crear serias incompatibilidades o bugs.

Hay una muy buena posibilidad de que con varias plugins se pueda intentar cubrir un mismo propósito, intenta utilizar siempre la plugin mas completa, compatible, la mejor en general que no de problemas, evita usar muchas plugins para lo mismo a no ser que sea 100% completamente necesario.

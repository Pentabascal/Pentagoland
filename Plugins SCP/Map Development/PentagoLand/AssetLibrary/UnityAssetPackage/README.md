# Pentagoland Unity asset pack

## Quick import

1. Use a Unity project with a compatible **Universal Render Pipeline (URP)** version installed. The included materials use the URP/Lit shader.
2. In Unity, choose **Assets > Import Package > Custom Package...** and open `Pentagoland_Assets.unitypackage`.
3. Keep the desired assets selected in the import dialog and click **Import**. Start with the ready-to-place assets under `Assets/Generated/Prefabs`; the gallery and material-study scenes are under `Assets/Generated`.
4. If you need physical collisions, inspect the separate prefabs in `Assets/Generated/CollisionPrefabs_Unassigned` and enable/configure their colliders only after checking scale and placement in your scene.

The package contains 113 FBX render models (109 utility props, three facility props, and one relay terminal), their texture folders, 113 separate compound collision prefabs, five URP/Lit material presets, source material references, review scenes, and import/collision reports. Utility-prop previews, editable Blender sources, GLB interchange files, and the 119 ProjectMER schematics remain available separately in the asset library; they are not all duplicated in this Unity package.

To regenerate and validate the package from source, run `PentagolandAssetReview\BuildReview.cmd`. It synchronizes the Blender exports, builds the Unity review assets, checks the reports, and writes `UnityAssetPackage\Pentagoland_Assets.unitypackage`.

The collision prefabs contain compound low-poly `MeshCollider` components, disabled by default and kept separate from render prefabs. Review them in the Inspector and in your target scene before enabling them. The generated material presets use the Universal Render Pipeline Lit shader; the target Unity project must have a compatible URP version installed.

The included Poly Haven metal-plate texture maps are CC0. Their source URL, license note, resolution, and verified file checksums are documented in `Assets/MaterialReferences/PolyHaven/MetalPlate/README.md`.

The build currently uses Unity **6000.6.4f1**. This package is a portable Unity content import, not a compiled SCP:SL AssetBundle and not a guarantee of compatibility with the game's Unity **6000.0.43f1** player. ProjectMER schematics remain separate JSON assets under `Samples\Schematics`; install and test those with ProjectMER on a staging server.

The `.unitypackage` is reproducibly generated by the checked-in review project. Unity caches, logs, and personal editor settings are not included.

# Plugins

## Carpetas principales

- `Activos/`: binarios de plugins listos para revisar y publicar individualmente.
- `7777/`: instalación del servidor para el puerto 7777.
- `Documentacion/`: memoria técnica, auditorías y guías del proyecto.
- `dependencies/`: dependencias compartidas del entorno.
- `backups/`: copias locales de seguridad no publicables.
- `staging/`: archivos de preparación o pruebas.

No se mezclan binarios, documentación ni archivos temporales en la raíz del directorio.

# Plugins activos

Cada plugin se mantiene en su carpeta individual para permitir publicar uno solo en GitHub sin mezclar HUD, APIs ni configuraciones.

## Carpetas principales

- `Exiled.CreditTags`
- `Exiled.CustomRoles`
- `Exiled.Events`
- `Exiled.Permissions`
- `CustomItemsAPI`
- `SubclassFramework`
- `VVUP.Base`
- `VVUP.CustomItems`
- `VVUP.CustomEscapes`
- `VVUP.MicroDamageReduction`
- `VVUP.PostNukeEnhancements`
- `VVUP.RoundStart`
- `VVUP.ScpChanges`
- `VVUP.ServerEvents`
- `VVUP.SubclassCompatibility`
- `VVUP.Votes`
- `VVUP.WeaponEvaporate`
- `XPSystem`

## Regla

No se sube un conjunto de HUD ni un paquete mixto. Cada plugin tiene su propia carpeta, su propio DLL y su configuración asociada si la requiere.

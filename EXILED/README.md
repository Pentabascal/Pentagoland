# EXILED server workspace

This folder contains the version-controlled server configuration, deployed-plugin inventory, and maintenance documentation for the local SCP:SL server.

## Contents

- `Configs/` — server permissions, plugin configurations, translations, and custom-item settings.
- `Plugins/Activos/` — the plugin DLL inventory and its installation notes.
- `Plugins/Documentacion/` — server state, compatibility notes, testing instructions, and changelog.
- `Plugins/README.md` — notes about the deployed plugin collection.
- `Instrucciones Proyecto IA/` — project maintenance references.

The installed SCP:SL game and dedicated-server runtime are kept outside this repository. Build output, logs, databases, and editor state are excluded by the repository `.gitignore`.

Plugin source projects and their supporting material live in the sibling `Plugins SCP/` folder at the repository root.
